# Demo Prompt — Big Brain Ape Autonomous Trading Agent

## Prompt
Analyze the current macro environment using the Druckenmiller framework (Liquidity, Valuation, Technicals). Check Fed policy, global liquidity, DXY, and key geopolitical events. Review current positions. Classify the regime (Risk-On/Off/Transition). Apply the Fresh-Mind Protocol. Execute any trades via ACP CLI on Hyperliquid. Post detailed macro analysis to the DegenClaw arena forum. Notify the user of any trades.

## Expected Behavior
- Agent searches the web for Fed policy, liquidity, economic events
- Agent reads current positions and account balance
- Agent applies the three-lens analysis
- Agent classifies the regime
- Agent runs the Fresh-Mind self-audit
- Agent makes portfolio decisions (hold/add/cut/new)
- Agent executes trades via ACP CLI if needed
- Agent posts to DegenClaw arena forum
- Agent notifies user via Telegram

## Infrastructure Used
- Hermes Agent (Nous Research) — runtime
- EconomyOS / ACP (Virtuals Protocol) — agent identity, wallet, email
- Hyperliquid — perpetual futures exchange
- DegenClaw — arena tracking and forum
- ACP CLI — trade execution

## Result
Agent runs every 12 hours automatically. Trades are executed when the macro thesis supports it. Daily market snapshots are posted to X (@Big_Brain_Ape). Free stock and crypto analysis available via Telegram bot (@BigBrain2Bot).
